# Кондитер ловит десерты

Браузерная аркада по мотивам классической игры «Волк ловит яйца».

Играть в браузере: https://bogdanovnae-ch.github.io/GameBaker/

На телефоне откройте именно эту ссылку (не страницу репозитория на github.com).

## Как играть

Нужен локальный сервер (модули JavaScript не открываются как файл):

```bash
npm start
```

Затем откройте http://localhost:4173

### Управление

Левая рука ловит слева, правая — справа. Раскладка не важна.

- **Верх слева:** Q W / Й Ц
- **Низ слева:** A S / Ф Ы
- **Верх справа:** O P / Щ З
- **Низ справа:** K L / Л Д
- **Пауза:** Esc

На телефоне после старта появляются кнопки слева и справа.
